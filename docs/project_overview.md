# Project Overview

This project is a simple web application that demonstrates real-time object detection using YOLO. The main objective is to detect and count objects from live camera streams and uploaded media. The application uses a pretrained model so that students can understand the complete pipeline without training a model from scratch.

The project is suitable for a B.E./B.Tech deep learning mini-project because it combines core concepts such as computer vision, object detection, web application development, and backend integration.

## Objective
The main goal is to detect common objects in images and videos and show the result in a browser. The application also shows the number of objects detected and the frames per second (FPS) rate for the live camera feed.

## Scope
- Webcam detection
- Image upload detection
- Video upload detection
- Bounding boxes and labels
- Object counting
- Real-time FPS monitoring

## Learning Value
Students can learn:
- how YOLO works at a high level
- how OpenCV is used for video processing
- how Flask connects the frontend and backend
- how to process AI output for summarization and counting
